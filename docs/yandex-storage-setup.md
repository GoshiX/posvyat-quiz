# Настройка Yandex Object Storage

Изображения загружаются через админку квиза: сервер подготавливает файл и сохраняет его в выбранный бакет. Параметры находятся в разделе «Настройки → Хранилище изображений» и общие для рабочего режима и репетиции.

Для бакета `posvyat2026` нужны сервисный аккаунт, роль на бакет и статический ключ доступа.

## 1. Создайте сервисный аккаунт

В [консоли Yandex Cloud](https://console.yandex.cloud/) выберите каталог с бакетом. Откройте **Identity and Access Management → Сервисные аккаунты → Создать сервисный аккаунт**, задайте имя **posvyat-upload** и нажмите «Создать». [Инструкция Яндекса по созданию аккаунта](https://yandex.cloud/ru/docs/iam/operations/sa/create).

## 2. Разрешите запись в бакет

Откройте **Object Storage → posvyat2026 → Безопасность → Права доступа → Назначить роли**. Выберите сервисный аккаунт **posvyat-upload**, нажмите «Добавить роль», выберите **storage.editor** и сохраните.

Роль назначается на этот бакет. Пошаговый путь приведён в [инструкции по IAM-доступу к бакету](https://yandex.cloud/ru/docs/storage/operations/buckets/iam-access).

## 3. Получите Access Key ID и Secret Access Key

Вернитесь в **Identity and Access Management → Сервисные аккаунты → posvyat-upload**. Нажмите **«Создать новый ключ → Создать статический ключ доступа»**, укажите описание, например `quiz-images`, и создайте ключ.

Скопируйте **идентификатор ключа (Access Key ID)** и **секретный ключ (Secret Access Key)**. Секрет показывается только в окне создания и после его закрытия недоступен; сохраните оба значения сразу. Для квиза нужны именно параметры статического ключа. [Инструкция Яндекса по статическим ключам](https://yandex.cloud/ru/docs/iam/operations/authentication/manage-access-keys).

## 4. Разрешите чтение изображений

В бакете откройте **«Настройки → Основные»**. В блоке «Доступ» установите **«Для всех» только для чтения объектов**, затем сохраните. Это позволит участникам и проектору открывать загруженные изображения по их адресам. Публичный список объектов и чтение настроек для квиза не требуются. [Настройка публичного доступа](https://yandex.cloud/ru/docs/storage/operations/buckets/bucket-availability).

Анонимную запись не разрешайте: загрузку выполняет сервер с ключами сервисного аккаунта. CORS для обычного показа изображений через `<img>` с другого домена не требуется; браузер передаёт файл серверу квиза, а сервер отправляет его в Object Storage.

## 5. Сохраните и проверьте настройки квиза

1. Откройте **«Настройки → Хранилище изображений»** в админке квиза.
2. Оставьте бакет **posvyat2026**, вставьте **Access Key ID** и **Secret Access Key**. Переключатель загрузки пока оставьте выключенным.
3. Нажмите **«Сохранить хранилище»**. Оба поля ключей очистятся; подпись подтвердит, что значения сохранены на сервере.
4. Нажмите **«Проверить хранилище»**. Проверяются сохранённые настройки. При несохранённых изменениях кнопка недоступна.
5. После успешной проверки включите **«Загружать в Object Storage»** и снова нажмите **«Сохранить хранилище»**. Для включения должны быть сохранены оба ключа.

Адрес S3 API — `https://storage.yandexcloud.net`, регион — `ru-central1`. Эти параметры заданы приложением. Публичный адрес изображений отображается в форме и для этого бакета начинается с `https://storage.yandexcloud.net/posvyat2026`.

Теперь новые иконки групп, изображения карточек и логотипы загружаются в бакет. После загрузки сохраните соответствующую форму группы или оформления, чтобы применить полученный адрес. Ранее сохранённые изображения сохраняют свои адреса.

Пустые поля ключей при следующем сохранении сохраняют действующие значения. Для замены вставьте новые значения и сохраните настройки. Ключи повторно в форме не отображаются.

Если проверка не проходит, проверьте имя бакета, оба значения статического ключа, его принадлежность аккаунту **posvyat-upload** и роль **storage.editor** на бакет. Если загрузка прошла, но изображение недоступно посетителю, проверьте публичное чтение объектов.
